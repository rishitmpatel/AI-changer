## Download

| Your computer | File | Then |
|---|---|---|
| **Windows 10/11** | `AI-Switch-Windows.zip` | Extract → open the `AI Switch` folder → double-click **AI Switch.exe** |
| **macOS 11+** | `AI-Switch-macOS.zip` | Extract → drag **AI Switch** to Applications → right-click it → **Open** |

No Python, no installer. AI Switch uses the Microsoft Edge or Google Chrome you already have.

**Windows says "Windows protected your PC"?** The app isn't code-signed yet, so SmartScreen warns about it.
Click **More info → Run anyway**. This only happens the first time.

**macOS says the app "can't be opened"?** Right-click (or Control-click) the app → **Open** → **Open**.
If it says the app is damaged, run `xattr -cr "/Applications/AI Switch.app"` once in Terminal.

## What it does

Pick the AI your memory is in now and the AI it should go to, then click **Start**.
AI Switch reads what the first AI remembers, shows you any phone numbers, emails or addresses so you
can remove them, adds the memory to the second AI, then checks what it recalled and re-sends anything missing.
Your memory only goes to those two AI websites — no analytics, no other servers.
